# 03: 窄屏单抽屉两段

**What to build:** ≤860px 的抽屉里同时容纳图层段与对话段，不再需要两个独立入口。

**Blocked by:** 01, 02

**Status:** ready-for-agent

**Size:** S

## Acceptance Criteria

- [ ] 抽屉内部是纵向两段：图层段在上（最高 `min(360px, 50%)`，可折叠）、对话段在下且 `flex: 1`。
- [ ] 分隔条在 ≤860px 隐藏；抽屉宽度仍为 `min(320px, 86vw)`，≤560px 占满整宽。
- [ ] 抽屉打开时滚动只发生在图层列表与消息列表内部，抽屉本身不滚。
- [ ] Esc 关闭抽屉后焦点回到「图层」按钮（现有行为保留）。
- [ ] 390×844 下手测：抽屉打开后能同时看到至少 2 行图层与 2 条消息。

## Notes

- 不新增第二个抽屉按钮；顶部「图层」按钮打开的就是这个两段抽屉。
