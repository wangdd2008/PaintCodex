# AI 对话与 AI 图层

## 初始状态

- 面板标题按钮：`AI 对话 ▾`，可折叠；展开时 `aria-expanded=true`。
- 空状态：`向绘画助手咨询构图、配色，或者下一步该画什么。`
- 输入框 placeholder：`描述你想画的内容…`，没有 `<label>` 或 `aria-label`。
- 输入为空时「发送」禁用。
- 输入非空时出现「清空」；点击后输入清空，按钮变成「撤销」；再点恢复原文。只支持一次撤销，符合设计。
- 回车发送，Shift+Enter 换行（源码逻辑）。

## 成功链路现场测试

输入「画一个红色圆形」并发送：

1. 用户消息立即出现。
2. 助手气泡显示 `AI 正在思考…`，输入框禁用，按钮变为「取消」。
3. 约 20 秒后，图层列表出现 `AI — 红色圆形`，类型 `✦ AI`。
4. 助手最终文本：`好的，我给你画一个红色圆形。`
5. 成功后工具栏撤销可用。

现场记录：

```json
{
  "chat": "你\n\n画一个红色圆形\n\nAI 助手\n\n好的，我给你画一个红色圆形。",
  "error": null,
  "layer": "AI — 红色圆形",
  "steps": []
}
```

- 成功后的 `steps` 为空：`AI 正在思考…` 等步骤只在 in-flight 时显示，完成后消失。
- 从发送到图层出现约 19 秒；期间只有一行“思考中”，没有已用时间、进度或预计等待。
- AI 图层名称由 AI 返回的 action name 决定，用户不能改名。

## 取消链路现场测试

输入「画一座山」并发送，1.2 秒后点「取消」：

```json
{
  "chat": "你\n\n画一个红色圆形\n\nAI 助手\n\n好的，我给你画一个红色圆形。\n\n你\n\n画一座山\n\nAI 助手\n\n已取消",
  "error": null,
  "send": "发送",
  "cancel": null
}
```

- 取消后按钮恢复「发送」，输入框恢复可用。
- 取消的助手气泡显示 `已取消`。
- 取消没有产生新图层。
- 取消在监控中被记录为 `chat_completed` 的 `warn`，并带 `aborted: true`；AI 成功率统计会把这次取消算作一次 chat、0 次成功。

## 刷新后的会话状态

刷新页面：

- 画布与 AI 图层保留（`AI — 红色圆形`）。
- 对话历史清空，恢复为空状态文案。
- 输入框草稿也丢失。

结论：作品持久化，但对话上下文不持久化；用户无法回看上一轮提示或 AI 的解释。

## 无画布时聊天

在无画布状态发送「你好」，AI 正常回复并建议“在画布上添加一层新的矢量图形”。没有前置提示或自动建画布；如果用户继续要求作画，没有承载目标。

## 错误处理

- 错误显示在输入框上方的红色 `role="alert"` 区域。
- 超时错误会映射为「请求超时，请重试」。
- 其他错误保留后端文本；初始兜底文案为「AI 助手无法响应。请检查 Codex CLI 是否已安装并已登录。」
- 没有重试按钮；用户需要重新输入或重新发送。
- 错误发生后输入框保留原草稿（发送时已清空输入，错误后没有自动恢复）。

## AI 图层与选择

- AI 图层出现在图层面板，带 `✦ AI` 标记。
- 「选择」工具只对 AI 图层生效；可以移动/缩放，变换后写回 SVG 内容（源码 `object:modified`）。
- 没有颜色/样式编辑；要改颜色只能重新提示 AI，可能生成新图层。
- AI 生成后没有“已添加图层，可撤销”的提示；用户可能不知道画布已变化（尤其在画布可视区域之外时）。

## 面板与布局

- 折叠 `AI 对话` 只隐藏聊天主体，图层区域不受影响。
- 8 个图层时聊天区高度从约 467px 被压缩到 186.75px。
- 聊天消息区 `max-height: 280px`，自身可滚动；外层侧栏也会滚动。
