# 09: 图层名称、透明度与类型

**What to build:** 把协议与渲染已经支持的 `name`、`opacity` 暴露到界面，并把类型显示中文化；一次拖动只产生一个撤销步。

**Blocked by:** 05 (类型/名称中文化), 06 (行布局)

**Status:** ready-for-agent

**Covers:** UX-13

**Size:** M

## Acceptance Criteria

- [ ] 行内重命名：双击名称或点小按钮进入，Enter 或失焦提交，Esc 取消，空值回退原名；PATCH 失败回滚并就地提示。
- [ ] 透明度滑块 0–100%：拖动只做本地预览，松手（`change`）才发 PATCH；一次拖动 = 一个撤销步。
- [ ] 透明度设为 40% 后，撤销一次回到拖动前的值。
- [ ] 类型显示「笔迹」/「AI」/「图片」，不出现 `vector`。
- [ ] 改名后列表、刷新页面、导出 JSON 三处都是新名。
- [ ] 不改 `zIndex`（协议不支持，属于 Phase 2 扩展）。
- [ ] 自动化：断言 Esc 不产生 PATCH；断言拖动过程中 fetch 次数为 1（松手时）。

## Notes

- 名称与透明度都作用于「该行」，与选中语义无关（票 08）。
- 类型中文化若与票 05 的白名单检查重复，以票 05 的扫描为准，本票只负责渲染。
