# 13: 连接状态指示

**What to build:** 画布页不再对 SSE 断线一无所知：状态栏给出「连接中／实时中／重新连接中」，断线用琥珀色而非红色错误，恢复后自动刷新一次。

**Blocked by:** 02 (状态栏槽位)

**Status:** ready-for-agent

**Covers:** UX-17

**Size:** S

## Acceptance Criteria

- [ ] 状态栏小圆点 + 短文案，复用监控页的视觉语言；三态：连接中 / 实时中 / 重新连接中。
- [ ] 打开画布 ≤1 秒显示「实时中」。
- [ ] 停 daemon ≤3 秒显示「重新连接中」。
- [ ] 恢复 daemon ≤5 秒回到「实时中」，并自动刷新一次画布。
- [ ] 断线用琥珀色，不使用红色错误横幅（它不是操作失败）。
- [ ] 读屏只播报一次状态变化（`role="status"`），不逐次朗读。
- [ ] 不新增轮询请求（`onOpen` 后单次刷新即可）。
- [ ] 自动化：模拟 SSE `error` 事件 → 断言状态文案与颜色类；模拟 `open` → 断言刷新调用 1 次。

## Notes

- 现状：`onError` 未接入 `App.tsx`，画布页无任何连接指示，而监控页已有完整 live 状态。
- 不提供手动重连与离线队列（架构是「失败即报错 + 全量刷新」）。
