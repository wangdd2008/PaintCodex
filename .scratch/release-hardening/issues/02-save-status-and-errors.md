# 02: 保存状态、错误横幅与失败保留

**What to build:** 删除每 30 秒自动下载 JSON 的 effect；在状态栏建立唯一的保存状态；保存失败时不再移除笔画，而是保留、标记未保存、提供重试；画布级错误改为画布区顶部横幅。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Covers:** UX-02, UX-08

**Size:** M

## Acceptance Criteria

- [ ] `App.tsx` 的 30 秒自动下载 effect 被删除；新建画布空闲 30 分钟，Downloads 新增文件数为 0。
- [ ] 画一笔后 ≤1 秒状态栏显示「已保存」；连续 5 笔内每条笔画只经历一次「保存中 → 已保存」，不来回抖动（防抖 ≤500ms）。
- [ ] 空闲时显示相对时间：≤15 秒「刚刚」，之后「N 秒前」，≥60 秒「N 分钟前」。
- [ ] 停 daemon 再画一笔：≤2 秒画布区顶部出现 `role="alert"` 横幅，含中文原因与「重试」；该笔画仍留在画布上并标为未保存。
- [ ] 点「重试」成功后横幅消失、笔画进入快照、状态栏回到「已保存」；刷新页面后笔画仍在。
- [ ] 若重试会造成重复路径（Fabric 对象无法与服务端快照对齐），降级为移除笔画 + 横幅明说「这一笔未保存」；**不得静默移除**。
- [ ] 横幅生命周期：mutation 失败时出现；该 mutation 重试成功或用户手动关闭时消失；`refreshCanvas` 成功不清除。
- [ ] 状态栏显示真实缩放，替代硬编码的「缩放: 100%」：1264×625 下为 44.7% ±1%（由 canvas 元素渲染宽度 / 1920 计算，窗口变化实时更新）。
- [ ] 状态栏信息去重：画布名/尺寸/比例/工具/保存状态各出现一次，移除画布内重复 hint。
- [ ] 顶栏不再承载主要错误（`.menu-status` 的红字可保留为摘要，但详细原因与重试在横幅里）。
- [ ] 自动化：daemon 不可达时组件测试断言笔画对象仍存在且横幅出现；断言 `saveStatus` 序列为 saving → saved。
