# 07: 图层命中区与可见性语义

**What to build:** 图层行里的按钮达到可点尺寸；可见性控件的名字与状态不再自相矛盾；图标语义可辨且不只靠颜色。

**Blocked by:** 06 (面板布局先稳定)

**Status:** ready-for-human

**Covers:** UX-10

**Size:** S

## Acceptance Criteria

- [ ] 图层行内所有可点元素的命中区 ≥24×24；可见性控件 ≥28×28；相邻控件间距 ≥4px。
- [ ] 行高 36–40px；命中区靠热区扩展实现，不放大字形。
- [ ] 浏览器 200% 缩放下控件不被裁切。
- [ ] 可见性控件读屏不再出现「显示 Stroke 1，未按下」这类动作/状态矛盾：`aria-label` 固定为「{name} 可见性」，`aria-pressed` 表示是否可见。
- [ ] 图标语义可辨（眼睛/斜线），hover 与 focus 时显示文字提示；不只靠颜色传达状态。
- [ ] 8 层时图层面板高度 ≤300px（与票 06 的约束一致）。
- [ ] 可视化验收：截取 100% 与 200% 两张图，控件边界清晰、无重叠。

## Notes

- 现状：可见性按钮 `font-size: 11px; padding: 0`（约 11px 高，字形宽约 7px），删除按钮 `font-size: 16px; padding: 0 2px`（约 16×16）。精确尺寸来自审计的 DOM 测量，源码只固定了高度。
- 本票含视觉平衡判断（热区与视觉重量的取舍），因此标记为 `ready-for-human`。
